# ADR-0007: the pipeline of a public repository - every check, every bot, the branch protected

- Status: accepted
- Date: 2026-11-24

## Context

The repository is public, so GitHub-hosted runners cost nothing, and until now the pipeline used
them sparingly: lint on push, the drills once a week, four actions pinned by sha and nothing to
move them, no bot, no branch protection, code scanning and secret scanning off, Dependabot off.
A red weekly run stayed red for three weeks because nothing but a human looked at it.

## Decision

- **Lint, one tool per job, every push and pull request**: ansible-lint with yamllint and the syntax
  check, shellcheck, actionlint (the workflows), hadolint (the image; DL3008 off by `.hadolint.yaml`:
  the base packages ride Ubuntu's branch as ADR-0006 rides PGDG's), markdownlint (prose at 120,
  tables free), gitleaks. Each job is a required status check of `main`.
- **The drills on every pull request that touches the cluster** (roles, scripts, the compose files,
  the image, the pins) and weekly on `main`; the evidence is an artifact and a table in the job
  summary (`scripts/lib/evidence_summary.py`).
- **The bots**: Dependabot for the actions (sha and tag together), the base image's digest and the
  pinned python tools of `requirements-ci.txt`; GitHub's own Dependabot alerts, secret scanning
  with push protection and CodeQL default setup (python and the workflows) turned on through the
  API. Renovate would group the updates and is the recorded alternative; Dependabot needs no app.
- **Every action pinned by its commit sha** with the release tag beside it; `step-security/harden-runner`
  on every job, egress audited; `ubuntu-24.04` named, never `latest`; python 3.13 because the pinned
  ansible-core 2.22 wants it.
- **OpenSSF Scorecard** weekly and on push, results published; the README carries the badge.
- **A ruleset on `main`**: no deletion, no force push, changes through a pull request with the lint
  jobs green. The author merges his own pull requests - one person, no review quorum to invent - but
  nothing lands red.

## Consequences

Every change is a branch, a pull request and a green set of checks; a weekly drift (a new PGDG
build, a moved action) is a pull request from a bot or a red run that names its cause. What is not
done: a self-hosted runner, a container registry for the image, deployment anywhere - the lab is the
product, and the pipeline proves the lab.
